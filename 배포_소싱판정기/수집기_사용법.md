# 윙 요율표 수집기 사용법

입출고배송비 요율표를 윙 화면에서 그대로 읽어 JSON으로 모으고,
소싱판정 대시보드에 한꺼번에 넣는 방법입니다.

준비물 두 개 — 같은 폴더에 있습니다.

- `윙요율표수집기.js`
- `소싱판정_대시보드_v4.1.0.html`

---

## 1단계 · 윙 요금표 화면 열기

크롬으로 윙에 로그인한 뒤 아래 주소로 들어갑니다.

```
https://wing.coupang.com/tenants/rfm/settlements/fee-details
```

화면에 **입출고비 / 배송비** 표가 보이면 맞게 오신 겁니다.

---

## 2단계 · 개발자 도구 열기

키보드 **F12** 를 누릅니다. 화면 오른쪽(또는 아래)에 창이 하나 붙습니다.

그 창 위쪽 탭 중에서 **Console** 을 클릭합니다.
(한국어로 바꾸겠냐고 물어보면 아무거나 눌러도 됩니다)

---

## 3단계 · (막혔을 때만) 붙여넣기 허용하기

**평소엔 건너뛰세요.** 바로 4단계로 가시면 됩니다.

4단계에서 붙여넣는 순간 크롬이 노란 경고를 띄우며 막을 때가 있습니다.

> 경고: 이해하지 못했거나 직접 검토하지 않은 코드는 DevTools 콘솔에 붙여넣지 마세요. …
> 붙여넣기를 허용하려면 아래에 "붙여넣기 허용"을 입력하고 Enter 키를 누르세요.

**그때만** 콘솔에 아래를 **직접 타이핑**하고 엔터를 치세요. 복사·붙여넣기 말고 손으로 칩니다.

| DevTools 언어 | 입력할 말 |
|---|---|
| 한국어 | `붙여넣기 허용` |
| 영어 | `allow pasting` |

**경고창에 적힌 문구를 그대로 치면 됩니다.** 크롬 언어에 따라 달라집니다.

그다음 다시 붙여넣으면 됩니다. 한 번만 하면 이후로는 안 물어봅니다.

> 막히지도 않았는데 미리 치면 `Uncaught SyntaxError: Unexpected identifier` 오류가 납니다.
> 크롬이 그냥 자바스크립트로 해석해서 나는 오류이고, **아무 문제 없습니다.**

---

## 4단계 · 수집기 실행

`윙요율표수집기.js` 를 메모장으로 열고 **전체 선택(Ctrl+A) → 복사(Ctrl+C)** 합니다.

콘솔에 붙여넣고(Ctrl+V) 엔터.

화면 **오른쪽 아래에 작은 흰 패널**이 나타나면 성공입니다.

```
요율표 수집기
0개 저장됨
[ 이 표 저장 ]
[ JSON 내보내기 ]
[ 목록 보기 ]
[ 전부 비우기 ]
```

---

## 5단계 · 모으기 (이것만 반복)

1. 윙 화면에서 **카테고리 선택하기** 를 눌러 카테고리를 하나 고릅니다
2. 표가 다시 그려질 때까지 잠깐 기다립니다
3. 패널의 **[이 표 저장]** 을 누릅니다
4. 1번으로 돌아갑니다

패널에 이렇게 뜹니다.

- `저장: 반려/애완용품 > 고양이용품 > ... (18구간)` — 새 표가 들어갔습니다
- `중복 — OOO 에 경로만 추가` — 이미 같은 내용의 표가 있어서 경로만 붙였습니다. **정상입니다.** 여러 카테고리가 요율표 하나를 같이 쓰기 때문입니다
- `빈칸 N` 이 같이 뜨면 못 읽은 칸이 있다는 뜻입니다. 알려주세요

### 주의 — 천천히 하세요

빠르게 연속으로 카테고리를 넘기면 쿠팡이 자동화로 보고 접속을 막습니다.
사람이 표를 보는 속도면 충분합니다. 한 카테고리에 10~20초쯤 쓰세요.

막혔다면(Access Denied 화면) 창을 다 닫고 20~30분 뒤에 다시 하세요.

### 중간에 그만둬도 됩니다

저장한 내용은 브라우저에 남습니다. 컴퓨터를 껐다 켜도 그대로입니다.
다시 할 때는 **4단계만 다시** 하면 이어서 쌓입니다.

---

## 6단계 · 파일로 내보내기

다 모았으면 패널의 **[JSON 내보내기]** 를 누릅니다.

다운로드 폴더에 이런 파일이 생깁니다.

```
wing_fee_2026-08-25.json
```

---

## 7단계 · 대시보드에 넣기

1. `소싱판정_대시보드_v4.1.0.html` 을 엽니다
2. **쿠팡 로켓그로스** 를 고릅니다
3. 위쪽 **어드민** 탭을 누릅니다
4. **입출고배송비 요율표** 카드에서 파란 버튼 **[수집기 JSON 가져오기]** 클릭
5. 방금 받은 `wing_fee_....json` 선택

`3개 추가 · 1개 갱신했습니다` 같은 메시지가 뜨면 끝입니다.

이제 홈 화면 **요율표** 드롭다운에 새 카테고리들이 나옵니다.
고르면 판매가와 사이즈에 맞는 입출고배송비가 자동으로 채워집니다.

---

## 참고

### 같은 이름이면 덮어씁니다

요율이 바뀌어서 다시 수집했다면 그냥 다시 가져오기 하세요.
이름이 같으면 새 값으로 교체됩니다.

### 요금 층

홈 화면 요율표 아래 **[요금 층]** 이 있습니다. 기본은 **전용할인가까지** 입니다.

- 전용할인가가 있는 칸 → 전용할인가
- 없으면 → 할인가
- 그것도 없으면 → 정상가

쿠팡이 공개한 값을 그대로 쓰는 방식입니다. 굳이 바꿀 일은 없습니다.

### 구버전 표

이름 옆에 `구버전` 이 붙은 8개는 예전에 스크린샷으로 만든 것입니다.
저가 구간이 뭉쳐 있고 전용할인가가 없어서 실제보다 비싸게 잡힙니다.
수집기로 다시 받아 같은 이름으로 넣으면 자동으로 교체됩니다.

---

## 안 될 때

**패널이 안 나온다**
콘솔에 빨간 글씨가 있는지 보세요. 스크립트를 일부만 복사했을 가능성이 큽니다. 전체 선택 후 다시.

**"요율표를 못 찾았습니다"**
카테고리가 선택되지 않은 상태입니다. 카테고리를 고르고 표가 뜬 뒤에 누르세요.

**붙여넣기가 안 된다 (노란 경고가 뜨며 막힌다)**
한글 크롬은 `붙여넣기 허용`, 영문 크롬은 `allow pasting` 을 손으로 타이핑하고 엔터.
경고창에 적힌 문구를 그대로 치면 됩니다. 그다음 다시 붙여넣으세요.

**`Unexpected identifier` 오류가 뜬다**
정상입니다. 붙여넣기가 이미 허용돼 있어서 나는 오류이니 그냥 4단계를 진행하세요.

**Access Denied 가 뜬다**
너무 빨리 넘긴 것입니다. 새로고침을 반복하지 말고 창을 닫은 뒤 20~30분 기다리세요.
